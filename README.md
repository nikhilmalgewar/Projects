## 🚀 Featured Projects
- **RAG with Langchain & Streamlit**
- – This repo is a small Streamlit application for resume screening. A user enters job requirements, uploads a PDF, DOCX, or TXT resume, and the app uses Google Gemini plus LangChain to assess how well the resume matches the role. Generated analysis is stored in a local Chroma vector store (chroma_store) for later retrieval.
